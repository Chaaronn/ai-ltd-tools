Ideation: Evolution Lab additions

Ranked directions for what to add next to the Evolution Lab — the evaluate-only coaching tab over .evolution saves — without abandoning its honesty grammar or sole-write keeper boundary.

Grounding Context

Codebase context. Evolution Lab reads %APPDATA%\AI Learns To Drive\evolution\*.evolution, analyses in memory, and writes only an optional (best lap) keeper copy. Pipeline: forks → runs → verdict → compare, plus overview, designs, advice, projection, and netviz. Fair comparison splits runs when settings, rewards, track, or architecture change; forks dedupe shared prefix history; verdicts use placebo-calibrated |z| and speak Helped / Hurt / can’t tell with evidence strength labels.

  • Pain: median run ~4 generations; most setting changes untestable; sparse snapshot spacing; no activations in saves; design changes align to snapshot interval.
  • Leverage: advice and timing without game hooks; designs with-vs-without tables; fork structure as matched pairs; projection + stage playbook; P2 already names snapshot diff and stronger stats.
  • Boundaries: no auto-training, no editing .evolution, no applying settings in-game; CSV / notes / cloud / file-based sharing deliberately dropped.
  • External: adjacent neuroevolution explorers and local run trackers exist; no player-facing racing neuroevolution coach found. Game already treats settings as Discord-shareable currency.
  • Past learnings: no docs/solutions/ corpus in this repo.

Rank 1

Fork duel

Axis Run comparison and settings history Confidence 85% Complexity Medium
Description Today forks exist so copies never double-count evidence. Invert the leftover signal: two saves that share an identical generation-prefix and then diverge under different settings are a matched A/B from the same weights. Add a Fork duel panel that aligns siblings at own_from, compares lap gains over equal generation windows (fairness rules: same track/rewards, skip keeper empties), and pools pairs before claiming strong evidence.

Identical start, then diverging experiments — the Lab’s cleanest natural trial.

Basis direct: forks.rs shared-prefix / own_from (“copies never double the evidence”); advice.rs already recognises save-a-copy; compare fairness filters and pooled n≥5 gating reusable. reasoned: before/after verdicts fight short runs; parallel arms from the same weights shrink that confound.
Rationale This is the rare addition that creates stronger evidence without new game hooks — and it rewards a ritual players already do (copy before a risky change).
Downsides Real libraries may have few divergent-settings pairs; evolutionary noise and selection bias remain; keeper forks with identical settings must be excluded from “duels”.
Rank 2

Detectability / information-cost planner

Axis Training coaching and verdicts Confidence 80% Complexity Medium
Description Turn “wait N more gens” into a price list: given the player’s placebo |z| noise and current hold length, show the minimum detectable lap-gain (per 10 gens) that would clear the threshold now, and how many more generations would buy a smaller effect. After a WithinNoise verdict, say what size of effect was undetectable — so “can’t tell” stops meaning “do nothing happened”.
Basis direct: verdict.rs threshold() (95th percentile placebo |z|, fallback 4.4 below 50 points); gens_to_verdict / GUI “k more gens…”; spec success metric median run 4→15+. reasoned: MDE scales with noise × window length — the maths already sits in the Lab.
Rationale Longer holds are the product’s north-star behaviour change; players need a reason to hold that isn’t just “trust us”.
Downsides Fallback threshold dominates thin libraries; numbers can intimidate if poorly labelled; overlaps a “CantTell theatre” framing if both ship as larger surfaces.
Rank 3

One headline timing resolver

Axis Training coaching and verdicts Confidence 80% Complexity Low
Description Collapse stall (50 gens), projection flat (40), and netviz “not improving” (30) into one top-line instruction with a “why” that names which instrument fired. Keep the backup/keeper prompt first and separate. Preserve Stuck’s mutation-conditional wording.
Basis direct: three constants in runs.rs / projection.rs / netviz.rs; advice timing chain and diagnosis box speak independently today; tests assert first timing suggestion shape.
Rationale When three boxes disagree, players discount all of them. One instruction is the cheapest path to earlier stall intervention.
Downsides Hides intentional threshold nuance unless the “why” carries it; needs careful precedence table and test updates.
Rank 4

Swap card

Axis Network and sensor inspection Confidence 85% Complexity Low
Description Now training already flags barely-used non-raycast sensors and tells the player to check Network designs manually. Join the two: for each flagged sensor, list replacement candidates from designs with-vs-without evidence per stage, with n and strength labels (and “no evidence yet” when thin). Keep the weight-estimate caveat visible.
Basis direct: gui_lab.rs “candidates to swap… Check the inputs table…”; designs.rs features some-but-not-all networks use; “which 7” sensor budget copy.
Rationale Sensor choice is a once-per-network, high-leverage decision — the cross-tab is the step most likely to be skipped.
Downsides With/without evidence is confounded; weight-based usage can mis-rank; thin libraries show empty cards often.
Rank 5

Diagnosis-gated advice

Axis Network and sensor inspection Confidence 75% Complexity Low
Description Wire netviz::Diagnosis (Learning / Fine-tuning / Drifting / Stuck) into the advice resolver so channels stop contradicting each other: Learning silences playbook noise; Stuck elevates change-something playbook; Drifting suppresses “raise mutation” when already exploring. Suggestions remain shown-never-applied.
Basis direct: diagnosis lives in netviz/GUI; advice pipeline does not reference Diagnosis today; documented timing → playbook → own history → verdicts order.
Rationale Trust dies when Inside the network says Stuck and Suggestions still say “wait”. Gating restores one voice without new data.
Downsides Coarse state machine can hide useful weak hints; needs explicit precedence policy players can learn.
Rank 6

Cohort ghost / cold-start projection

Axis Lap projection and progress storytelling Confidence 75% Complexity Medium
Description When the own-series exponential fit is unavailable (<4 improvements, random track, early gens), borrow a library prior: percentile lap-by-generation envelopes for the same track/stage, labelled “others on this track”, with n. Optionally show how many gens sibling networks needed for −0.1 s from a similar starting lap.

When your curve is silent, the library still has a story — clearly labelled as borrowed.

Basis direct: projection.rs MIN_IMPROVEMENTS=4, random-track early return; comparable-runs already pools other networks at stage; spec metric “25% fewer gens to target on a new track”.
Rationale Projection is dark exactly when players most want a forecast — new track, new network. The library is the prior the Lab already owns.
Downsides Thin libraries yield empty bands; cross-network mix can mislead if vehicles/rewards differ; must never look like the own-fit.
Rank 7

Evidence clipboard card

Axis Sharing and social / build currency Confidence 70% Complexity Low
Description File-based sharing was dropped because it creates files. Add copy-to-clipboard only: a pasteable card with track, stage, best lap, diagnosis, strongest verdict + strength, and a one-line playbook recipe — no disk write (keeper remains the sole fs write). Defer paste-import until the game’s Copy-settings text format is known and testable.
Basis direct: spec drops CSV/notes/archives/sharing-as-files; lab_never_writes_files bans fs APIs only; overview::recipe already builds “how it got there”; no clipboard in Lab src today. external: game Copy settings for Discord; Pokémon/Showdown-style claim cards.
Rationale Unlocks the social loop players already have around settings, while advertising the Lab’s honesty labels — without reopening exports.
Downsides May be read as “sharing” against the spirit of the drop list; format churn; paste-import alone is blocked until the game’s text format is reverse-engineered.
